# METR — сайт-визитка с опросом-калькулятором

Одностраничный сайт компании **METR** — ремонт квартир, домов и коммерческих помещений под ключ в Краснодаре. Главная задача сайта — показать услуги и работы и собрать заявки через короткий опрос из 5 вопросов.

## Возможности

- **Лендинг из одного файла** — вся вёрстка, стили, скрипты и фотографии (23 JPEG в формате base64) находятся в одном `index.html`, без сборки и зависимостей.
- **Секции:** шапка с навигацией и телефоном, hero с каруселью фото, услуги, сданные объекты, галерея идей для интерьера с фильтрами, «Как работаем» (4 шага), опрос, контакты.
- **Опрос для расчёта стоимости** — имя, телефон или @username, тип объекта, площадь, число комнат, состояние объекта, наличие дизайн-проекта. Есть валидация обязательных полей.
- **Отправка заявки в Telegram** — после заполнения открывается Telegram с готовыми ответами, остаётся нажать «Отправить». Ответы также можно скопировать.
- **Мессенджеры и соцсети** — кнопки MAX, Telegram, Instagram и Taplink. При переходе в MAX текст сообщения автоматически копируется в буфер обмена.
- **Адаптивная вёрстка** для телефонов и десктопа, плавная прокрутка, учёт `prefers-reduced-motion`.
- **SEO и соцсети** — `title`, `description` и Open Graph-теги.
- **Тексты, телефон и фото можно подменять с сервера** — при загрузке сайт пробует получить контент через `GET /api/content`. Если сервер недоступен, показывается встроенная версия.

## Технологии

- HTML5, CSS3 (CSS-переменные, grid, flex, `clamp()`)
- Vanilla JavaScript (без фреймворков и библиотек)
- Шрифт [Unbounded](https://fonts.google.com/specimen/Unbounded) через Google Fonts
- Cloudflare Workers — для приёма заявок и отдачи контента (опционально)

## Запуск локально

Установка не нужна. Достаточно открыть `index.html` в браузере.

Или запустить локальный сервер:

```bash
# Python
python3 -m http.server 8000

# или Node.js
npx serve .
```

После этого сайт будет доступен по адресу `http://localhost:8000`.

## Публикация на GitHub Pages

1. Загрузите `index.html` в репозиторий (в корень ветки `main`).
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Нажмите **Save** — через пару минут сайт появится по адресу `https://<ваш-логин>.github.io/<название-репозитория>/`.

## Настройка

Основные настройки находятся в блоке `<script>` в `index.html`:

| Параметр | Назначение |
|---|---|
| `API_BASE` | Адрес сервера (Cloudflare Worker), откуда подгружается контент через `/api/content`. Если оставить пустым — используется тот же домен. |
| `LEAD_URL` | Адрес, на который отправляются заявки, если сайт размещён на статическом хостинге (GitHub Pages, Netlify и т. п.). |

Остальное правится прямо в разметке и в JSON-блоке `<script id="siteData">`:

- **Телефон** — поле `phone` в `siteData`.
- **Тексты** — элементы с атрибутом `data-k="..."` и раздел `texts` в `siteData`.
- **Цвета и оформление** — CSS-переменные в `:root` (`--brown`, `--oak`, `--plaster`, `--paper` и др.).
- **Ссылки на Telegram, MAX, Instagram, Taplink** — в блоке «Контакты» в конце страницы.
